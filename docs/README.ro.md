# Self-Correcting Public Link Parser

[Русский](../README.md) · [English](README.en.md) · [Română](README.ro.md) · [Українська](README.uk.md) · [中文](README.zh-CN.md) · [עברית](README.he.md)

**Colectarea, normalizarea și verificarea linkurilor disponibile public pentru cercetare, catalogare și analiză.**

Acest produs independent ajută echipele de cercetare, analiză și conținut să colecteze URL-uri publice, să le normalizeze, să elimine duplicatele și să controleze calitatea rezultatului.

## Principii

Se folosesc numai surse publice și scenarii compatibile cu regulile sursei. Utilizatorul este responsabil pentru drepturile de acces, termenii de utilizare și conformitatea aplicabilă. Produsul nu este destinat ocolirii limitelor, accesului neautorizat sau colectării de date private.
