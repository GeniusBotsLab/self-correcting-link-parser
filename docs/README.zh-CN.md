## 概述

用于从搜索结果中收集、规范化、验证并导出公开可访问链接的商业工作流，适用于研究、目录整理和分析。

## 链接如何收集

1. 设定合法目的、允许域名、排除规则、地区、语言、输出格式和请求频率限制。
2. 建立已批准搜索查询的队列，并记录状态和执行时间。
3. 仅处理无需登录即可访问的页面，并遵守来源规则、适用的 `robots.txt` 指令、停顿和速率限制。
4. 仅提取必要的公开字段：URL、标题、可见摘要、来源查询和发现日期。
5. 规范化 URL，并排除私有、登录、错误或超出范围的页面。
6. 按规范 URL 和域名去重，同时保留来源信息。
7. “自校正”指质量监控、在预先批准的提取配置之间切换或转交人工审查，而不是绕过任何保护。
8. 导出带来源和筛选日志的清理后 CSV、JSON 或表格。
