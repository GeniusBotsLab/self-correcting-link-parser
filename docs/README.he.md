## סקירה

תהליך מסחרי לאיסוף, נרמול, אימות וייצוא של קישורים ציבוריים מתוצאות חיפוש לצורכי מחקר, קטלוג וניתוח.

## איך מתבצע האיסוף

1. מגדירים מטרה חוקית, דומיינים מותרים, החרגות, אזורים, שפות, פורמט פלט ומגבלות קצב.
2. בונים תור של שאילתות חיפוש מאושרות עם סטטוס ומועדי הרצה.
3. מעבדים רק דפים זמינים ללא הזדהות, תוך כיבוד כללי המקור, הנחיות `robots.txt` רלוונטיות, השהיות ומגבלות קצב.
4. מחלצים רק שדות ציבוריים נחוצים: URL, כותרת, קטע גלוי, שאילתת מקור ותאריך גילוי.
5. מנרמלים כתובות URL ודוחים דפים פרטיים, דפי התחברות, שגיאות או תוצאות מחוץ להיקף.
6. מסירים כפילויות לפי URL קנוני ודומיין תוך שמירת מקור הרשומה.
7. תיקון עצמי פירושו ניטור איכות, מעבר בין פרופילי חילוץ שאושרו מראש או העברה לבדיקת אדם — לא עקיפת הגנות.
8. מייצאים CSV, JSON או טבלה נקיים עם מקור הנתונים ויומן סינון.
